# Навыки проекта

`.claude/skills/*` — документы, которые Claude Code подключает сам, когда задача
попадает под описание навыка. Их же можно читать глазами: это рабочие стандарты.

| Навык | О чём | Переносится в новый проект |
|---|---|---|
| `agent-workflow` | как агент ведёт работу: формат ответа, CHANGELOG, коммиты, проверки | **да**, без изменений |
| `tg-bot-style` | стиль экранов, голос героя, кнопки, эмодзи, лимиты | **да**, без изменений |
| `tg-bot-kit` | каркас бота: структура, настройки, база, доступы, деплой, грабли | **да**, без изменений |
| `dobrik-style` | частности «Марафона добрых дел»: Добрик, недели, задания | нет, это про этот проект |

## Как начать новый проект

1. Скопировать в новый репозиторий папки `agent-workflow`, `tg-bot-style`, `tg-bot-kit`.
2. Создать свой узкий навык вместо `dobrik-style`: имя героя, сущности предметной
   области, специфические правила. Общее не дублировать — на него сослаться.
3. Дальше по порядку из `tg-bot-kit` → «Порядок работы над новым ботом».

## Как писать навык

- один файл `SKILL.md` с заголовком `name` и `description`;
- `description` объясняет **когда** навык нужен, а не только о чём он: по нему
  принимается решение о подключении;
- длинные подробности — в `references/*.md`, на них ссылается `SKILL.md`;
- правило записывается вместе с причиной: почему иначе нельзя. Правило без причины
  через полгода нарушают первым.
