# Архитектурные решения

## Сессия и обработчик

```python
async with session() as s:
    user = await load_user(s, message.from_user)
    text, markup = await render_menu(s, user)
await edit(cq, text, markup)
```

Обработчик держит сессию ровно столько, сколько нужно: сначала данные, потом отправка.
Отправлять сообщение внутри открытой транзакции нельзя — сеть Telegram непредсказуема,
а соединение с базой платное.

## Состояние диалога

FSM живёт в памяти процесса, а процесс перезапускается (деплой, засыпание хостинга).
Поэтому **каждый шаг анкеты и каждый шаг мастера пишется в базу**, а на потерянное
состояние есть восстановление: пришло сообщение «в никуда» — определяем шаг по базе
и продолжаем с него.

Плюс — обработчик-перехватчик самым последним роутером: текст, фото или контакт,
не подошедшие никуда, не должны пропадать молча. Человек решит, что бот сломался.

## Отправка и редактирование

Один помощник `edit()` на весь проект: пробует `editMessageText`, при подписи под фото —
`editMessageCaption`, ловит «message is not modified» и не считает это ошибкой.

Id якорного сообщения хранится и в FSM, и в базе (`menu_message_id`).

## Middleware

| Middleware | Зачем |
|---|---|
| Премиальные эмодзи | подставляет `<tg-emoji>`, снимает их при отказе Telegram |
| Повтор запроса к базе | 3 попытки с паузами 1/3/6 с: облачная база просыпается не мгновенно |
| Логирование ошибок | ошибка обработчика не должна ронять поллинг |

## Альбомы

Несколько фотографий одним сообщением приходят как **разные апдейты** с общим
`media_group_id`. Без защиты каждое фото уйдёт в свой шаг мастера. Правило: в рамках
одного `media_group_id` принимаем файлы в тот шаг, на котором были в момент первого фото.

## Телефон

- кнопка `request_contact` живёт только в reply-клавиатуре и **не работает в Telegram
  Desktop** — в тексте всегда должен быть вариант «напишите номер сообщением»;
- убрать reply-клавиатуру можно только сообщением с `ReplyKeyboardRemove`, и это
  сообщение **нельзя удалять** — иначе кнопка останется висеть навсегда;
- номер без кода страны дополняется кодом из настройки;
- строка из цифр, присланная на шаге имени, — это номер, а не имя: сохранить и
  вежливо попросить имя.

## Экспорт

Выгрузка в Excel делается из тех же сервисов, что и экраны, — одна правда о данных.
Лист на сущность, первая строка — заголовки, ширина колонок задаётся, иначе файлом
неудобно пользоваться.
