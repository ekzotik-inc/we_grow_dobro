# Эмодзи и премиальные наборы

## Как это работает

Telegram разрешает боту **кастомные (премиальные) эмодзи** только пока у владельца
бота есть Telegram Premium, и **никогда не разрешает их в каналах**. Поэтому:

1. Каждый премиальный эмодзи хранится парой: `id` + обычный символ-замена.
2. В текстах пишутся **обычные** символы — они и есть запасной вариант.
3. На выходе middleware заменяет их на `<tg-emoji emoji-id="…">символ</tg-emoji>`.
4. Telegram отказал (Premium кончился) — бот снимает теги и продолжает работать.

```python
def e(name: str) -> str:
    emoji_id, fallback = CATALOGUE[name]
    if not enabled():
        return fallback
    return f'<tg-emoji emoji-id="{emoji_id}">{fallback}</tg-emoji>'
```

## Правила

- набор символов хранится данными (`data/premium_emoji.json`), не в коде — его можно
  пополнить, не трогая логику;
- символа нет в наборе → добавьте замену в таблицу `SUBSTITUTES` (`📋 → 📝`, `⚠️ → ❗`);
- автотест проходит по всем исходникам и падает, если найден символ без премиальной пары —
  это единственный способ не выпустить «простой» эмодзи наружу;
- в карточках каналов эмодзи всегда обычные: премиальные там не отображаются;
- выключатель на случай проблем: `PREMIUM_EMOJI=0`.

## Эмодзи в кнопках

Bot API 9.4 добавил кнопкам `icon_custom_emoji_id` и `style`. Ведущий эмодзи подписи
автоматически выносится в иконку:

```python
def _btn(text, cb, style=None):
    icon, label = button_icon(text)      # "📋 Задания" -> ("📋", "Задания")
    ...
```

**Осторожно:** если подпись состоит из одного эмодзи (выбор символа команды), выносить
нечего — иначе текст станет пустым и Telegram отклонит всю клавиатуру.

## Картинки профиля

| Что | Размер | Где |
|---|---|---|
| Аватар (botpic) | квадрат, от 512×512, обрезается в круг | BotFather → Edit Botpic |
| Description Picture | ровно 640×360 | BotFather → Edit Description Picture |
| Description Video | 640×360, ≤30 с, ≤1 МБ | заменяет картинку |
| Description | до 512 символов | виден до «Запустить» |
| About | до 120 символов | профиль и список чатов |

Картинки лучше генерировать скриптом из одного набора цветов и шрифтов — тогда обложки,
аватар и презентация выглядят одним проектом.
